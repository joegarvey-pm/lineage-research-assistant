# Skills — task recipes for the agent

Each file here is a procedure for one kind of task. They assume you have
already read `CLAUDE.md` and are bound by it.

**Read the one that matches the task at hand. Don't read all of them up
front.**

| Skill | Use it when |
|---|---|
| [`setting-up.md`](setting-up.md) | First session with a new user. Creates their workspace and gets the first real answer out of them. |
| [`research-brief.md`](research-brief.md) | The user asks *"what should I work on next?"* — produces a ranked, costed plan instead of a guess. |
| [`web-research.md`](web-research.md) | Searching an online archive. Covers the access rules, how to record a miss, and how to avoid a meaningless null. |
| [`document-inspection.md`](document-inspection.md) | Reading an actual record — a census page, a will, a certificate — and extracting what it really says. |
| [`record-sweep.md`](record-sweep.md) | Reading many unindexed images in sequence looking for one household. The long, grinding one. |
| [`tree-mapping.md`](tree-mapping.md) | The user wants to *see* the tree — generates markdown and Mermaid diagrams. |
| [`session-recap.md`](session-recap.md) | End of every working session. Writes the honest record of what happened. |
| [`session-prompt.md`](session-prompt.md) | Planning the *next* session as a reviewable brief before executing it. |

---

## The two habits that matter most

**1. Write the miss down.** Most research gets repeated because only the wins
were recorded. A logged "searched this, found nothing, here's my denominator"
is worth as much as a find.

**2. Say what you didn't do.** Partial work reported as complete is the one
failure that poisons everything downstream — a later session will build on it
as if it were settled.
